# 나의 할 일 목록

브라우저에서 바로 실행되는 간단한 할 일 관리 웹 앱입니다. HTML, CSS, JavaScript만으로 만들었으며 별도의 설치나 빌드가 필요 없습니다.

## 주요 기능

- **할 일 추가:** 버튼이나 Enter 키로 추가합니다. 빈 값과 이미 등록된 할 일은 추가되지 않습니다.
- **완료 표시:** 체크박스나 글자를 누르면 완료 상태가 바뀌고 취소선이 표시됩니다.
- **삭제:** 항목을 하나씩 지우거나 완료된 항목을 한 번에 지울 수 있습니다.
- **필터:** 전체, 진행중, 완료 항목을 나누어 볼 수 있습니다.
- **개수 표시:** 전체 할 일과 완료한 할 일의 개수를 보여 줍니다.
- **자동 저장:** 목록이 LocalStorage에 저장되어 새로고침해도 유지됩니다.

## 실행 방법

```bash
git clone https://github.com/hwangcheolhui/my-todo-app.git
cd my-todo-app
```

내려받은 폴더에서 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 |
| `style.css` | 화면 스타일 |
| `main.js` | 할 일 관리 기능과 LocalStorage 저장 |

## 참고 사항

할 일은 사용 중인 브라우저에만 저장됩니다. 다른 브라우저나 기기와 공유되지 않으며, 브라우저의 사이트 데이터를 삭제하면 목록도 함께 지워집니다.
